# 分析页 Demo(静态原型)

这个目录是**复盘分析页的交互原型**:用来评审「棋盘 + 走法树 + 最佳步骤行 + 评估曲线」的呈现方式,
不是线上代码的一部分,也不参与 `dotnet build`。

## 怎么看

页面用的是 ES Module(`chess.js`、`cm-chessboard` 都是 `import`),浏览器不允许从 `file://` 加载模块,
所以**必须用一个静态服务器打开**,不能直接双击 `index.html`。

```bash
# 在仓库根目录起一个静态服务器
python -m http.server 8080

# 然后浏览器打开
# http://localhost:8080/docs/htmldemo/
```

依赖的库直接引用仓库里已经 vendored 的版本(`src/ChessGameD.Web/wwwroot/lib/`),没有 npm、没有 CDN、不联网。

## 里面有什么

页面是**两栏**布局:

- **左栏**:棋盘(可在棋盘上试走)+ 竖向评估条 + 走法导航 → 当前局面(分值/深度/节点、主变 PV、候选着法)→ 评估曲线(可点击跳转,坏棋处有标记)。
- **右栏**:整局分析(带排队/进度的模拟,可中途停止)→ 走法与最佳行 → PGN。
  走法树在分析完成后,每个**失误 / 错误 / 严重失误 / 漏着**的正下方会紧跟一行「最佳步骤行」,
  显示引擎首着 + 后续续着 + 损失量;点这一行,棋盘会从出错前的局面开始逐步演示最佳续着(参考 lichess 的计算机分支)。
  「下一个问题手」按钮可以依次跳到每一处需要复盘的着法。

快捷键:`←` `→` 上一步/下一步,`Home` `End` 开局/终局,`F` 翻转棋盘。

## 数据说明

- 棋局走法来自 `samples/example.pgn` 里的不朽游戏,并用仓库自带的 `chess.js` 校验过合法性。
- **评估分值、走子分类、最佳续着都是手工编造的演示数据**,不代表引擎的真实结论。
- `assets/data.js` 由脚本生成,想改数据直接改这个文件即可(格式见文件开头的注释)。
